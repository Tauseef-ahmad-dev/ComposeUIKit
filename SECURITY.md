# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's **Report a vulnerability** option on this repository when private vulnerability reporting is available. If that option is unavailable, contact the maintainer through the contact details on the GitHub profile and include:

- A description of the affected component or dependency.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested mitigation.

Please avoid including real secrets, credentials, or personal data in reports.

## Scope

ComposeUIKit is a UI component library. Reports concerning unsafe rendering, unintended data exposure, dependency vulnerabilities, or accessibility/security regressions are welcome.
